SWOOPDL / LOCAL HELP

Browser integration

This guide is bundled with Swoopdl. It does not load websites, submit diagnostics, or require an internet connection.

Desktop app or host not installed

Install Swoopdl with browser integration selected. If you installed the extension before the app, finish the desktop installation, then reload the extension. The extension needs the com.swoopdl.host Native Messaging host registered by the installer.

Browser access is restricted

Confirm the extension is enabled and allowed to access the required sites. Check enterprise/browser restrictions if Native Messaging is disabled by policy.

Swoopdl is not responding

Start the desktop app, wait for it to finish opening, then reopen the extension. Try repairing the Swoopdl desktop installation if the connection still fails.

Native host could not connect

Restart the browser and the desktop app. Verify the installer registered the host and that the executable path still exists. Reinstall or repair Swoopdl if the registration is stale.

Message too large

Try a smaller batch of links. The browser-to-desktop messaging protocol has payload limits.

Version mismatch

Use matching Swoopdl desktop app and extension versions, then reload the extension.

A download stayed in the browser

Open the desktop app's integration settings and verify browser capture is enabled. File-type rules, exclusions, minimum size, or paused capture can leave a download with the browser by design.

Media visibility

Protected media cannot be downloaded through Swoopdl. Some players do not expose a direct media file or stream URL.

Site permission

Give the extension access to the website if you want it to capture downloads and cookies there. Restricted sites remain in the browser.

Another Swoopdl device

Pair only with a Swoopdl device you control using its secure address and pairing code. Pairing communicates with that device, but the extension never opens an unrelated support website.
