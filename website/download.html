Before you get started.

How do I build from source?

Use the Rust toolchain specified by the source checkout. From the repository root, run cargo build --workspace --locked. Build and test on your target operating system. Package builders have additional platform requirements listed in the README.

What should Firefox users know?

The bundled unsigned Firefox extension can be loaded temporarily through about:debugging. Firefox removes it after restart. Permanent installation in standard Firefox requires a Mozilla-signed extension.

Is macOS support ready?

macOS support is experimental. Validate the build on your system before relying on it. Check the macOS availability card above for a published package.
